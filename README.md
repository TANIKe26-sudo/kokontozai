# kokontozai

## 作品概要

悩みをうまく言葉にできない思春期の人や、つい言葉を飲み込んでしまう人に向けた、匿名のメッセージボトルアプリです。日々の小さなモヤモヤを短いメッセージにして、自分で飾ったボトルに詰めて海へ流します。ほかの利用者は流れ着いたボトルを開き、その気持ちにリアクションを返せます。

## 開発状況

現在は React + Vite で画面を開発しており、PHP API には稼働確認用の `GET /api/health` があります。以下は完成時の機能仕様です。投稿やリアクション、所持品などの保存には Laravel（PHP）と MySQL を使う予定です。

## 画面と機能

| 画面 | 利用者の操作とアプリの動作 |
| --- | --- |
| ホーム（島） | 読みたいジャンルを複数選び、いつでも変更・保存できる。保存したジャンルをもとに島に流れ着くボトルを選び、一覧とそれぞれの状態を表示する。 |
| 説明（チュートリアル） | 利用者ごとに、どの版のチュートリアルを読んだか記録する。説明を更新したときは、既読の利用者にも再表示するかを管理する。 |
| 桟橋 | ホームのジャンル設定にかかわらず、全ジャンルのボトルを状態付きで一覧表示する。タップしてタイトル＋序盤のみを確認し、それから拾うかを選ぶ。拾ったときに履歴を記録し、拾ったメッセージを取得できるようにする。獲得条件を満たせばデコレーションを所持品に追加する。 |
| ボトルメッセージ制作 | メッセージを入力する。投稿時に API で空欄・文字数・入力形式を検証し、修正が必要な項目を返す。下書きを採用する場合は、利用者が途中の文章を保存し、後で開いて書き直せるようにする。 |
| ボトルデザイン選択 | 選べるボトルと手持ちのデコレーションを確認し、本文・デザイン・装飾・ジャンルをまとめて投稿する。API 側でも装飾の所持を確認し、送信ボタンを二度押しても投稿は一件だけ作成する。 |
| デコレーション | デコレーションの一覧と所持状態を表示する。獲得したものは、いつ、どのボトルから手に入れたか確認できる。 |

### 匿名性とデータ管理

- 投稿は原則匿名。受け手には本文と投稿者が選んだボトルのデザイン・装飾が届く。投稿者名やプロフィール、内部の利用者 ID は受け手に公開しない。
- アプリ内部では匿名利用者も識別し、ジャンル設定、チュートリアルの既読状態、投稿、リアクション、拾った履歴、所持品を紐づける。
- 一覧 API は一度に返す件数を制限し、続きをページ単位で取得する。桟橋に置くボトルには、読み込み件数とは別に、総数と保持期間の上限を設ける。
- API の入力検証とエラー応答の形式を統一する。連続投稿の回数制限など、不正な連投や自動投稿を抑える仕組みを設ける。

## ディレクトリ構成

```text
kokontozai/
├── frontend/   # React + Vite
├── backend/    # PHP API
└── README.md
```

画面で使う画像素材は `frontend/public/images/` に置きます。React からは `<img src="/images/photo.png" alt="説明" />` のように参照します。

## 開発に必要なもの

- Git
- [Node.js 22 LTS](https://nodejs.org/en/download/)（22.12 以上。npm も一緒にインストールされます）
- [PHP 8.4 以上](https://www.php.net/downloads.php)（CLI を使えること）

PHP はインストール後、`php` コマンドをターミナルから実行できるよう PATH を設定してください。

インストール確認:

```sh
git --version
node --version
npm --version
php --version
```

## 初回セットアップ

リポジトリを clone したあと、フロントエンドの依存パッケージをインストールします。

```sh
git clone https://github.com/TANIKe26-sudo/kokontozai.git
cd frontend
npm ci
```
(npm ciの代わりにnpm installでも多分可能)

## 開発サーバーの起動

ターミナルを2つ開き、フロントエンドとバックエンドをそれぞれ起動します。

ターミナル1（React）:

```sh
cd frontend
npm run dev
```

ターミナル2（PHP）:

```sh
cd backend
php -S 127.0.0.1:8000 -t public public/router.php
```

ブラウザで `http://localhost:5173` を開きます。

(PHP API は `http://127.0.0.1:8000/api/health` で確認でき、フロントエンドからは Vite の proxy を通して `http://localhost:5173/api/health` で呼び出せます。どちらも `{"status":"ok"}` が返れば起動できています。)


サーバーを止めるときは、それぞれのターミナルで `Ctrl+C` を押してください。
